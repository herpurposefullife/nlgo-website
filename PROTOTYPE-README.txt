NEW LIFE GLOBAL OUTREACH — WEBSITE PROTOTYPE
Internal notes for Jaanu / ELIM Admin Hub — not part of the client-facing site.

PROTOTYPE STATUS
Visual Discovery Prototype — Not Final.
Built to walk Pastor John Ezekiel and the NLGO team through a proposed site
structure at the second discovery meeting. All content is placeholder or
clearly marked "to be confirmed" — nothing here should be treated as final
copy, dates, names, or figures.

HOW TO OPEN
Unzip the package, then double-click index.html. It opens in any browser
and works fully offline — no server or install needed. Every page links to
the others with real navigation (not just anchors on one long page).

WHAT'S CLICKABLE
- Full desktop nav + mobile hamburger menu on every page
- Logo returns to Home from anywhere
- Ministries page: each ministry expands as an accordion
- Bible School page: enquiry form with validation + demo "submitted" state
- Events page: each event card opens a detail view with a registration form
- Give page: giving-category pills, amount pills (with "other amount" reveal),
  donor form, and a demo "Give securely" button that shows a demo success message
- Contact page: contact form + separate prayer-request form, both with the
  same demo-submit behaviour
All forms are front-end only — nothing is actually sent or processed.

- Real contact details, address, and social media accounts
- Real upcoming events and how registrations are currently handled
- Who manages the website day-to-day, and who receives prayer requests
